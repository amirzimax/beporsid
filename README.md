# MVP چت‌بات فروشگاه (تست با Gemini رایگان)

## مراحل اجرا

1. **نصب Node.js** (اگر نصب نداری، از nodejs.org دانلود کن، نسخه 18 به بالا)

2. **نصب پکیج‌ها:**
   ```
   npm install
   ```

3. **گرفتن کلید API:**
   - به https://aistudio.google.com/apikey برو
   - با اکانت گوگل وارد شو و یک کلید بساز

4. **تنظیم کلید:**
   - فایل `.env.example` را کپی کن و اسمش را `.env` بگذار
   - کلید خودت را جای `your_gemini_api_key_here` بگذار

5. **اجرای سرور:**
   ```
   npm start
   ```
   پیام «سرور چت‌بات روی پورت 3000 در حال اجراست» را می‌بینی.

6. **تست:**
   فایل `test-widget.html` را در مرورگر باز کن و شروع به چت کن.

## نکات مهم

- اطلاعات فروشگاه در `shop-data.json` است — همین الان می‌توانی محصولات واقعی خودت را جایگزین کنی.
- روی تیر رایگان، حداکثر حدود ۱۵ درخواست در دقیقه مجاز است؛ در تست پشت سر هم پیام نفرست.
- وقتی به چند مشتری رسیدی، این معماری (تزریق مستقیم کاتالوگ در پرامپت) دیگر جواب نمی‌دهد و باید به سراغ vector database و روش RAG بروی — فعلاً برای MVP کافی است.
- برای production حتماً باید API Key پولی (Vertex AI) جایگزین کلید رایگان شود، و کلید هرگز نباید در کد سمت کاربر (فرانت‌اند) قرار بگیرد — همیشه فقط در بک‌اند.

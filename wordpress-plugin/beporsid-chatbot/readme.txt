دستیار هوش مصنوعی فروش که به محصولات، قیمت و موجودی واقعی ووکامرس وصل می‌شود و ۲۴ ساعته به مشتری‌ها جواب می‌دهد.

== Description ==

بپرسید یک چت‌بات هوش مصنوعی فارسی برای فروشگاه‌های اینترنتی است:

* جواب ۲۴ ساعته با قیمت و موجودی واقعی ووکامرس
* پیشنهاد محصول جایگزین وقتی کالایی ناموجود است
* پیگیری سفارش با کد سفارش
* ارجاع گفتگو به کارشناس انسانی (در پنل یا با Reply در تلگرام)
* پایگاه دانش از فایل، صفحه‌های سایت و سوال‌وجواب

این افزونه اتصال را ساده می‌کند: یک «کد اتصال» از پنل بپرسید می‌گیرید و این‌جا وارد می‌کنید. افزونه خودش کلید فقط‌خواندنی ووکامرس را می‌سازد و ویجت چت را روی سایت می‌گذارد؛ نیازی به ساخت کلید API یا ویرایش قالب نیست.

= سرویس خارجی =

این افزونه برای کار کردن به سرویس بپرسید (https://beporsid.com) وصل می‌شود:

* هنگام اتصال: آدرس سایت و یک کلید REST «فقط خواندنی» ووکامرس به https://api.beporsid.com فرستاده می‌شود تا دستیار بتواند محصولات و وضعیت سفارش را بخواند.
* در صفحه‌های سایت: اسکریپت ویجت از https://api.beporsid.com بارگذاری می‌شود و پیام‌هایی که بازدیدکننده در چت می‌نویسد برای پاسخ به همین سرویس فرستاده می‌شود.

شرایط استفاده و حریم خصوصی: https://beporsid.com/

== Installation ==

1. افزونه را نصب و فعال کنید.
2. در پنل بپرسید (https://api.beporsid.com/dashboard.html) ثبت‌نام کنید.
3. در پنل به «تنظیمات ← اتصال فروشگاه ← ووکامرس» بروید و «ساخت کد اتصال افزونه» را بزنید.
4. در پیشخوان وردپرس، منوی «بپرسید» را باز کنید، کد را وارد کنید و «اتصال» را بزنید.

== Frequently Asked Questions ==

= بپرسید می‌تواند چیزی را در فروشگاه من تغییر دهد؟ =

نه. کلیدی که افزونه می‌سازد فقط دسترسی خواندن دارد.

= سایتم ووکامرس ندارد. کار می‌کند؟ =

بله. ویجت نصب می‌شود و دستیار از پایگاه دانشی که در پنل می‌سازید جواب می‌دهد.

= سایتم باید HTTPS باشد؟ =

برای خواندن محصولات ووکامرس بله؛ ووکامرس اجازه‌ی این نوع اتصال را روی HTTP نمی‌دهد. ویجت روی هر سایتی کار می‌کند.
